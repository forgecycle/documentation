# Surface: documentation site (all pages + landing)

Mode: Read. Audience: practitioners mid-task looking up commands, config keys, recovery steps. Landing page is a docs index (Read), not marketing.

## Direction contract

THESIS: Every page is a serially numbered technical-log sheet: entries are added, never torn out, and nothing is released until signed off. Refuses the stock three-column template with tinted accent and splash hero.

OWN-WORLD: Cool carbonless-copy paper ground (#f3f5f2), one deep form-ink blue (#1f3570) for frame, rules and field labels, serial red (#c4321f) only for serials, stamps and the marked line. Field labels in condensed caps; reading face is a calm humanist sans; mono only for code. Ruled field boxes on an 8px module. Asides carry printed stamp labels (state is a mark, not a hue; raise from cutting-bench). Solid ink masthead, not a tint (raise from plakatstil). Single 8px ruling module (raise from brick instructions). Highlighted code lines marked in serial red (raise from zine). Roles coded D/P/B/R consistently (raise from dumbar). Dark: night-shift copy, ink-navy ground.

STORY: Reader knows where they stand (section, page, source version), finds the answer in the column, moves on via index or next/prev.

FIRST VIEWPORT: Solid ink masthead: logo + wordmark left, top nav (Start, Concepts, Guides, Reference) centered, search, version printed as SHEET Nº in red right. Docs pages: ruled field row (Section / Page / Source) above the title, sidebar as the log INDEX, right TOC. Landing: the log sheet's header block with the tagline, then the loop as a four-entry ruled log (D/P/B/R) and a ruled index of the four sections.
